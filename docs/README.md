# Documentation

This directory can contain additional documentation for your GitHub profile:

- **portfolio.md** - Detailed project portfolio
- **resume.md** - Markdown version of your resume
- **skills.md** - Detailed technical skills breakdown
- **experience.md** - Work experience and achievements
- **contact.md** - Contact information and links

## Purpose

While the main README.md serves as your GitHub profile landing page, this docs folder provides space for more detailed information that you can link to from your main profile.
