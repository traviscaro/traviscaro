# Assets Directory

This directory contains assets for the GitHub profile:

- `images/` - Profile pictures, project screenshots, banners, etc.
- Other asset types can be organized in subdirectories as needed

## Usage

You can reference images in your README.md like this:
```markdown
![Profile Banner](assets/images/banner.png)
```

Make sure to add images that are:
- Appropriately sized for web viewing
- Optimized for fast loading
- Relevant to your professional profile
